# **Week 05 – Kerberos and Access Control**

## **Overview**

During Week 05, I studied **Kerberos authentication and access control concepts** used to protect systems, users, and network resources.

## **What I Studied**

- **Kerberos Authentication**
- **AS-REQ, AS-REP, TGS-REQ and TGS-REP**
- **AP-REQ and AP-REP**
- **Ticket Granting Tickets (TGT) and Service Tickets**
- **Kerberos Security and Replay Protection**
- **Golden Ticket, Silver Ticket and Pass-the-Ticket Attacks**
- **Identification, Authentication, Authorisation and Accounting**
- **Subject, Object and Action**
- **Role-Based Access Control (RBAC)**
- **Mandatory Access Control (MAC)**
- **Discretionary Access Control (DAC)**
- **Attribute-Based Access Control (ABAC)**
- **Bell-LaPadula Security Model**
- **Least Privilege and Separation of Duties**
