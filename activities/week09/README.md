 # Week 09 – Wireless Security and Network Access Control

## Overview

During Week 09, I studied wireless network security and different threats that can affect Wi-Fi networks. I learned how wireless networks operate, the security protocols used to protect them, and how common wireless attacks can be identified.

## What I Studied

In this week, I learned about:

- Wired and wireless network differences
- Wi-Fi security protocols including WEP, WPA, WPA2 and WPA3
- WPA2-Personal and WPA2-Enterprise
- 802.1X authentication
- WPA2 4-way handshake
- EAPOL-Key messages
- Evil Twin attacks
- Rogue Access Points
- Deauthentication attacks
- Eavesdropping
- KRACK attacks
- Offline dictionary and PMKID attacks
- Wireless traffic and threat identification
- Network Access Control (NAC)
- Posture assessment
- Quarantine and production VLANs
- NAC remediation workflow

## Learning Outcome

After completing Week 09, I developed a better understanding of how wireless networks are secured and how attackers can target Wi-Fi connections. I also learned how to recognise different wireless attacks by examining network behaviour and captured frames.

I gained an understanding of how WPA2 authentication works through the 4-way handshake and how enterprise authentication can provide individual access control for users.

The Network Access Control activities also helped me understand how organisations can check the security status of devices, place non-compliant devices into a quarantine VLAN, allow remediation, and then move compliant devices to the production network.
