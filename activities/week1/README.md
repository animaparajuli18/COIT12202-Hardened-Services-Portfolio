# Week 1 – GNS3 Introduction and Network Configuration

## Overview
This activity was about basic network configuration done in GNS3. I practised configuring network interfaces, assigning IP addresses, and testing connectivity between virtual nodes.

## Tasks Completed
- Configured networking interfaces in GNS3.
- Assigned IP addresses to virtual nodes.
- Checked interface configuration.
- Tested connectivity between nodes using ping.
- Practised basic network troubleshooting.
