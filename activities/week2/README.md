# Week 2 – PKI, Digital Certificates and TLS

## Overview
This week was focusing Public Key Infrastructure (PKI), digital certificates, HTTPS and TLS. The activities demonstrated how certificates establish trust and how TLS protects communication between a client and server.

## Activities Completed

- HTTPS & TLS
- TLS 1.3 Handshake Walker / Cert-Chain Walker
