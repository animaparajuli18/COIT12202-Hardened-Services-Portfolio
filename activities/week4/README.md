# Week 4 – Hardened Services

## Overview
This week focused on hardening network services and improving system security. The activities included configuring secure services, testing access controls, and verifying that security measures were working correctly.

## Activities Completed
- Configured and tested secure network services.
- Applied security hardening configurations.
- Tested authorised and unauthorised access.
- Verified that security controls were functioning correctly.
- Practised secure service configuration using GNS3.
